FATHIMATH SAHALA PORTFOLIO

1. Extract this zip. Copy the sahala-portfolio folder wherever you like (it replaces the old one).
2. Open index.html in a text editor and fill in WHATSAPP, EMAIL, INSTAGRAM, FACEBOOK in the <script> block.
3. REPLACING DUMMY IMAGES: keep the same file names (e.g. images/dummy-ladies-1.jpg) and overwrite them with your photos
   (900x1200 px portrait, under 300 KB). Or change the paths in the 'items' list in index.html.
4. Preview: double-click index.html.
5. Deploy: Cloudflare dashboard -> Workers & Pages -> Pages -> Drag and drop your files -> upload the folder.
